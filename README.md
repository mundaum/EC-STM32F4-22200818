## Contents

This repository contains:

- **include/** : Header files and custom library source codes
- **lab/** : Embedded Controller LAB assignments
- **lib/** : Additional library files
- **tutorial/** : PreLAB and tutorial source codes

## Environment

- **Program Language:** C / C++
- **IDE:** Visual Studio Code
- **Build Environment:** PlatformIO
- **Framework:** CMSIS
- **MCU:** STM32F411RE

## Installation

1. Open the project in Visual Studio Code.
2. Select the PlatformIO environment.
3. Build and upload the code to the Nucleo-F411RE board.
